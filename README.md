# PolyGen — Text-to-3D Asset Pipeline

PolyGen is a web application prototype for creating and managing 3D assets from text prompts.

## Features
- Text-to-3D generation interface
- 3D asset preview interface
- FastAPI backend
- React and Vite frontend
- Tripo AI API integration

## Tech Stack
- Python
- FastAPI
- React
- Vite
- Tripo AI API

## Project Status
Prototype in development. API authentication and end-to-end 3D generation are still being tested.

## Run Locally
See the backend and frontend folders for setup instructions.

## Security
Keep API keys and `.env` files private. Never commit credentials to GitHub.
